# Student Management System (C++)

This project is a menu-driven console application to manage student records using file handling in C++.

## Features
- Add a student
- View all students
- Update a student by ID
- Delete a student by ID
- Persistent storage in `students.txt`

## Build
```bash
g++ -std=c++17 main.cpp -o student_management
```

## Run
```bash
./student_management
```
